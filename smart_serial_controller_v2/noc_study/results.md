- yosys `synth_xilinx -flatten -noiopad` (no I/O buffers, like Vivado out-of-context).
  LUTs = logic LUTs + LUTs used as distributed RAM for the FIFOs (RAM32M = 4 LUTs).
  Vivado usually needs fewer LUTs (better wide-mux mapping); use the ratios, not the exact values.
- logic levels = longest chain of LUT / MUXF7 / MUXF8 / CARRY4 cells between two
  flip-flops (yosys `ltp`), a rough stand-in for the clock speed: more levels, lower Fmax.
  The distributed-RAM read at the start of the path is not counted.
